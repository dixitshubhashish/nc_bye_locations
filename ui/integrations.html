How this works

1. Map a source

Choose a brand and source format independently. Select Upload File, Public URL, GET API, or Python Editor, then click Parse. Parsing inspects a small sample to discover fields and values.

2. Confirm the model

Source Preview shows the actual records. Data Model shows source fields on the left and target listing fields on the right. Required fields appear first; green mappings are recognized and light-red mappings are suggestions to verify.

3. Save and review

Saving reloads the complete source, not only the discovery sample. Valid records continue into reporting. Invalid records remain available in Review Error Listings for manual edits or automatic enrichment.

4. Use the tabs

  • Mappings: ingest sources, map fields, manage brands, and start enrichment.
  • Review Error Listings: search, edit, retry, and monitor automatic fixes.
  • Template Library: reuse saved field mappings with lazy loading and pagination.
  • Reporting: compare brands, identify ZIP gaps, inspect location coverage, and review data quality improvements.

5. Understand the numbers

Reporting uses the latest available location and quality data. The app may refresh background data quietly, while explicit refresh actions show progress. Filters apply only to the active reporting view.
